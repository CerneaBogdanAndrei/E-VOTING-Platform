# Macheta inițială

Prima variantă a criptografiei: ElGamal exponențial pe grupul MODP 2048 (RFC 3526), într-o pagină HTML și un modul JS, cu 22 de teste (`node test.mjs`). A fost înlocuită de `packages/crypto` (ristretto255, conform planului) și e păstrată pentru istoric și pentru capitolul de evoluție a soluției din lucrare.
